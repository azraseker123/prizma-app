# PRİZMA — Gün 1

Soft Luxury AI tasarım dilinde hazırlanmış Expo + React Native Android başlangıç projesi.

## Başlatma

Node.js LTS kurulu bir bilgisayarda:

```bash
npm install
npx expo start
```

Android cihazda Expo Go ile QR kodu açılabilir. Sürüm uyumluluğu sorunu olursa Expo SDK ve Expo Go sürümlerini eşleştirin.

## Önemli

Bu sürümdeki ekranlar yalnızca **arayüz prototipidir**. Gerçek AI, kullanıcı hesabı, fotoğraf yükleme, abonelik veya veritabanı henüz bağlı değildir. Herhangi bir gizli anahtarı bu depoya eklemeyin.

## Dosyalar

- `App.tsx`: İlk 5 sekmeli uygulama arayüzü
- `app.json`: Expo yapılandırması
- `package.json`: Bağımlılıklar
- `tsconfig.json`: TypeScript ayarları
- `.gitignore`: Git'e yüklenmemesi gereken dosyalar
